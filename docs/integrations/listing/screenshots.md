# Claude Apps card screenshots

Capture three to five screenshots during the live Claude acceptance journey, at the dimensions and cropping the Claude submission page requires on the day. Use the reviewer account; crop out tokens, signed URLs, and personal data.

1. Upload card: file chosen, committed generation settings visible.
2. Progress card: Operation Status for a generation, showing clips finished.
3. Clip review card: preview with scores and timing.
4. Publication confirmation card: the exact post before confirmation.
5. Export result: the export with its granted output (shown as text if no card renders it).
