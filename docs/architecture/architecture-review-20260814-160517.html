Problem

The Project module accepts reaped-but-still-alive workers, yet failure and several completion paths do not fence by attempt identity.

Solution

Concentrate claim identity, heartbeat, retry, completion, failure, reaping, and event publication in one deep Workflow Run module.

  • locality: one transition owner
  • leverage: every worker stage
  • tests hit one interface
  • stale attempts become harmless
