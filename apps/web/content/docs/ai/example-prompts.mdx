Name the Workspace or Project when you have more than one. Ask for status to follow work that takes a while.

## Look around

```text
List my Narriflow Workspaces and tell me how many credits are left this month.
```

```text
Show my Projects in the Studio Workspace and say which are still processing.
```

## Make clips

```text
Import https://www.youtube.com/watch?v=VIDEO_ID with the Acme Brand Profile. I want 8 clips of 30 to 60 seconds.
```

```text
How is that import going?
```

```text
Show the five highest-scoring clips in the latest Project. Give a one-line reason for each.
```

## Export and deliver

```text
Export the first clip in 9:16 at 1080p, then tell me when it is ready.
```

```text
Give me the download links and the SRT subtitles for that export.
```

```text
Prepare a client review link for these two exports.
```

```text
Has the client approved the review round?
```

## Publish

```text
Show my connected publishing accounts.
```

```text
Prepare a TikTok post for the first clip on Friday at 9:00 with this caption: "Three mistakes new founders make". Show me the exact post before scheduling anything.
```

## Automate

```text
Create an RSS Autopilot rule for https://example.com/feed.xml that checks daily and imports up to 3 episodes.
```
