  </Step>
</Steps>

## Install with mcp.json

Add the server to `~/.cursor/mcp.json`, or to `.cursor/mcp.json` in one project.

```json
{
  "mcpServers": {
    "narriflow": {
      "url": "https://api.narriflow.example/mcp"
    }
  }
}
```

Cursor starts the sign-in the first time it connects.

## Use a Workspace API key

For unattended runs, send a Workspace API key instead of signing in. Create the key in **Settings → Developer access** and keep it in an environment variable.

```json
{
  "mcpServers": {
    "narriflow": {
      "url": "https://api.narriflow.example/mcp",
      "headers": {
        "Authorization": "Bearer ${env:NARRIFLOW_API_KEY}"
      }
    }
  }
}
```

If sign-in fails, see [Troubleshooting](/docs/ai/troubleshooting).
