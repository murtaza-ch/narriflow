---
title: Connect Claude
description: Add Narriflow to Claude on the web, in the desktop app or in Cowork as a custom connector.
---

<Steps>
  <Step title="Add the connector">
    In Claude, open **Customize → Connectors**, select **+ Add**, then **Add custom connector**.

    On Team and Enterprise plans, an organization Owner adds the connector under **Organization settings → Connectors**. Members then connect it from **Customize → Connectors**.
  </Step>
  <Step title="Enter the URL">
    Name it `Narriflow` and paste the URL.

    ```text
    https://app.narriflow.com/mcp
    ```

    Select **Continue**. Keep the authentication settings Claude detects, then select **Add**.
  </Step>
  <Step title="Sign in and approve">
    Sign in to Narriflow and approve the access Claude asks for. If Claude does not start the sign-in, select **Connect** next to Narriflow. Read access is granted by default. Approve write access only for what you want Claude to do.
  </Step>
  <Step title="Turn it on in a chat">
    In a conversation, select **+**, then **Connectors**, and switch Narriflow on.
  </Step>
  <Step title="Confirm it works">
    Ask Claude to list your Narriflow Workspaces. It should call `narriflow_list_workspaces` and show each Workspace with its role and whether the connector is enabled.
  </Step>
</Steps>

To disconnect, remove the connector under **Customize → Connectors**.

For plan limits and admin controls, see Claude's guide to [custom connectors](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp). If sign-in fails, see [Troubleshooting](/docs/ai/troubleshooting).
