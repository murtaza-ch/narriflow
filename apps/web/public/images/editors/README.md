# Video editor icons

Shown on the export page's "Edit in your own editor" tiles. Trademarks belong to their respective owners. Preserve the supplied geometry; only the monochrome mark is recoloured for dark mode.

- [premiere.svg](https://svgl.app/library/premiere.svg) — Adobe Premiere, from [SVGL](https://github.com/pheralb/svgl), 2026-10-28.
- davinci-resolve-light.svg / davinci-resolve-dark.svg — DaVinci Resolve, from [Simple Icons](https://simpleicons.org) 16.36.0 (CC0-1.0), 2026-10-28; filled with the brand colour `#233A51` (light) and `#F2F2F2` (dark).

Final Cut Pro has no icon here: Apple doesn't license its product icons for third-party use, and the open icon sets don't carry it.
