---
title: Connect ChatGPT
description: Add Narriflow to ChatGPT as a custom MCP server.
---

<Steps>
  <Step title="Add a custom MCP server">
    Open [ChatGPT Plugins](https://chatgpt.com/plugins), select the plus button, then **Add custom MCP server**.
  </Step>
  <Step title="Enter the connection details">
    Give it a name such as `Narriflow` and a short description. Under **Connection**, paste the URL.

    ```text
    https://app.narriflow.com/mcp
    ```
  </Step>
  <Step title="Choose OAuth">
    Set authentication to OAuth, accept the risk warning, then select **Create as a plugin**.
  </Step>
  <Step title="Sign in and approve">
    Sign in to Narriflow and approve the access ChatGPT asks for. Read access is granted by default. Approve write access only for what you want ChatGPT to do.
  </Step>
  <Step title="Use it in a chat">
    Start a conversation, type `@`, and select Narriflow. Ask ChatGPT to list your Narriflow Workspaces to confirm the connection.
  </Step>
</Steps>

<Note>
  Whether you can add a custom MCP server depends on your ChatGPT plan and your organization's settings. If the option is missing, ask a ChatGPT admin. OpenAI documents the current steps in [Connect and test your plugin](https://developers.openai.com/plugins/deploy/connect-chatgpt).
</Note>

To disconnect, remove Narriflow in ChatGPT. If sign-in fails, see [Troubleshooting](/ai/troubleshooting).
