# Review of ticket 05 (Sol, 2026-11-27) with the orchestrator's decisions

Branch `feat/title-text-services` at b770ec5cc. Fix on that branch with a regression test each (fast suites only).

1. **High. A changed seed during staging strands the run.** `clip-selection-preparation.ts` (~line 192): when the recomputed capsule hash differs from the staged one while the run is still `queued`/`waiting` and has no windows, it returns `superseded`, and the driver (`clip-selection-control.ts` ~line 51) completes as superseded without settling the run or retrying. Any brand change does this today; the title settings add one more way. Decision: in that case throw a retryable `WorkflowFailure` (for example `selection_input_changed`) instead of returning `superseded`, so the transaction rolls back and the next attempt stages the current capsule. Keep `superseded` for the genuinely superseded cases (run not current, wrong status). Check what the staged storage objects and cleanup obligations do on that path (they are admitted in an earlier transaction with a delayed `notBefore`, so a retry should leave them to the existing cleanup), and say so in the ticket.
2. **Medium. One unreadable clip aborts Apply to all.** A clip whose stored document or `editorOriginal` fails to decode throws in the bulk read (`clip-editor-document-persistence.ts` ~1255 / ~1065) before the per-clip skip runs. Decision: in the project-selection read, a row that fails to decode is skipped and counted (for every patch kind, not only titles), keeping its id and revision for the commit guard if the guard needs them; the other clips still update. The response's `skipped` count includes it for title patches.
3. **Medium. An unreadable brand snapshot fails generation.** `clip-detection-persistence.ts` ~106 parses the snapshot's caption preset with `.parse` and throws. Decision: `safeParse`; on failure fall back the same way as when there is no template preset.
4. **Low. Apply to all moves timing that already fits.** A 9.8-10.0 title becomes 9.5-10.0 on another 10 s clip. Decision: keep the patch's interval when it fits the target clip (`start < duration` and `end <= duration` or open); only when the target forces a change, clamp the end to the duration and apply the 0.5 s floor. Remove the unreachable `endSec <= startSec → null` fallback or make it impossible by construction.
5. **Low. Counts.** A title request that touches no clip returns `field: "framing"` with no counts; in a title-plus-background group a background-only change counts as `restyled`. Decision: the field and counts come from the requested patches (a title request always answers `field: "title"` with counts, zeros included), and `restyled` counts clips whose title layer actually changed.
