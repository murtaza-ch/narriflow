# Review of the core branch (Sol, 2026-11-27) with the orchestrator's decisions

Branch `feat/title-text-core` at 3f1e23756. Fix on that branch, one commit per item or small group, with a regression test each.

1. **High. The golden runner cannot render `text-layers-transition`.** `apps/media/scripts/render-golden.ts` (~line 1070) writes the caption script and compiles the command without `textAssPath`, so the case throws `clip_composition_text_asset_missing`. Write the text script per target there as the render attempt does and pass its path. Do not run the golden suite (it renders); read it through instead.
2. **Medium. Control characters reach the ASS file.** A layer text `A\u0000B` writes a raw NUL: libass draws `A`, drops `B` and skips the next layer. In the layout's text normalisation (`drawnText`, shared by both renderers) remove C0/C1 control characters other than the line break, and turn a tab into a space. Stored documents keep parsing; both renderers see the same text.
3. **Medium. Audiogram frame rate.** The text writer plans on a 30 fps grid for audio-only inputs while the audiogram feeds the filter 25 fps frames (`clip-render-attempt.ts` ~3760), so a short title can burn one frame long or not at all. Pass the audiogram's real rate to the text writer and to its recovery path.
4. **Medium. Start and end frames at NTSC rates.** ASS times are centiseconds and the writer rounds: a title starting at 1.209 s misses frame 29 at 24000/1001 (PTS 1.209542 s, ASS start 1.21). For static pieces choose the frames from the filter's PTS (rational rate): the event starts at the first active frame's time floored to a centisecond and ends at the first inactive frame's time floored to a centisecond, so it includes the first active frame and excludes the first inactive one. Test 24000/1001, 30000/1001, 60000/1001, 25 and 30. Scene Style pieces on the sampled path must not change.
5. **Medium. Title pinning moves titles.** Decision: on a trim, extend or cut a `role: "title"` layer keeps its start. If its window still touches the clip (`startSec < newDuration`), only its end is clamped to the new duration, with no 0.5 s floor (a start of 2.8 on a clip trimmed to 3 stays 2.8). If it no longer touches the clip (`startSec >= newDuration`), the layer is left exactly as it is: the plan already skips an empty range, and extending the clip brings it back. Open ends stay open. Body layers keep today's rebase and floor.
6. **No action here.** The Studio preview still drawing an uploaded font is resolved by ticket 03, which paints with the scene painter and catalog faces.
7. **Rejected.** Wrapping keeps the box padding reserved whether or not a background is on: otherwise switching Background on would re-wrap the text.
8. **Low.** `wrapTextLayer` treats a no-break space (U+00A0, U+202F, U+2060-joined text) as a wrap point and rewrites it as a space: split on ordinary spaces only and keep the others inside their word. `cutTitleText("ab؀ cde", 5)` cuts inside a grapheme when backing off to a space: back off on grapheme boundaries.
