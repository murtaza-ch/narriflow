# Text-to-image replacement for gpt-image-2 (research read 2026-11-13)

Use case: text-free B-roll/overlay images, 1024x1536 (9:16), 1536x1024, 1024x1024, quality medium, `POST /v1/images/generations`.
Legend: [P] = price read today from the provider's own page. [H] = price from a host page (fal etc.). [D] = derived by me from official numbers (math shown). [U] = unverified (secondary source only, or page did not render).

## 1. OpenAI

Deprecations page https://developers.openai.com/api/docs/deprecations (read today):
- `gpt-image-2` and `gpt-image-2-2026-04-21`: deprecated, notice 2026-11-10, shutdown 2027-02-10. Recommended replacement: "gpt-image-2.6-sunburst or gpt-image-2.6-flare".
- Same replacement for `gpt-image-1-mini`, `gpt-image-1.5`, `chatgpt-image-latest`: shutdown 2026-12-01.
- `gpt-image-1` shut down 2026-10-23 (replacement listed: gpt-image-2.5-sunburst/flare). dall-e-2/3: 2026-05-12.
- No image-specific migration steps beyond "compare outputs, latency, and cost before switching". gpt-image-2.5-* is NOT on the deprecation list today.
- There is no "mini" in the 2.x family. The only mini is gpt-image-1-mini (shutdown 2026-12-01).

Pricing https://developers.openai.com/api/docs/pricing [P]: all of gpt-image-2, 2.5-{sunburst,flare}, 2.6-{sunburst,flare} are $8 image-in / $30 image-out / $5 text-in per 1M tokens (cached image-in $2, text $1.25). Batch table lists 2.5 and gpt-image-2 only (image-out $15/M), not 2.6. The page has no per-image table for 2.x; it points to the calculator in https://developers.openai.com/api/docs/guides/image-generation.
Per-image at 1024x1536 comes from that guide's calculator source (`GptImageTokenCalculator.react.7TppeEsP.js`, formula and token constants read directly). I reproduced the published gpt-image-2 table with it ($0.041 medium 1024x1536, $0.053 medium 1024x1024) and AA's $210.72/1k at 1024² for max, so the formula is trustworthy, but token counts are estimates. Check `usage` on a test call. [D]

At 1024x1024 2.6 medium is $0.0435, 2.5 medium $0.0132. 1536x1024 equals 1024x1536.
- 2.6 medium is 17% cheaper than gpt-image-2 medium. 2.5 medium is 75% cheaper.
- Sunburst = "editing precision"; Flare = "fast, high-quality everyday generation". Same token price.
- New `complexity` field (low/medium/high), default high. "No separate fee", but higher complexity "can increase latency and introduce unwanted changes". Keep quality medium, set complexity low or medium for B-roll.
- Sizes: 1024x1024, 1536x1024, 1024x1536 recommended; custom WxH multiples of 16, ratio 1:3 to 3:1, 655,360 to 8,294,400 px.
- Latency: no numbers published. Square is "typically fastest" (gpt-image-2 section).
- Data (https://developers.openai.com/api/docs/guides/your-data): API data not used for training by default; abuse-monitoring logs up to 30 days; ZDR/MAM available. Images endpoints are ZDR-eligible for gpt-image-2.5 variants, gpt-image-2, 1.5, 1-mini. 2.6 was not named in that list, so confirm before promising ZDR.
- Model-id caveat: the guide's code samples use `gpt-image-2.5-*`; the deprecations/pricing pages use `gpt-image-2.6-*`. Confirm the exact 2.6 ids with `GET /v1/models`.

## 7. Ranked shortlist to audition (render the same 20 Studio prompts x 4 styles x 3 sizes, blind compare)
1. DEFAULT, easiest migration: `gpt-image-2.6-flare`, quality medium, complexity low/medium. Same endpoint and params; only the model id changes (plus optional `complexity`). $0.034 at 1024x1536 [D] vs $0.041 today. LMArena 1384 vs 1382 for gpt-image-2 medium (statistically tied, prelim).
2. CHEAPER, same API: `gpt-image-2.5-flare` medium, $0.0103 at 1024x1536 [D] (about 3x cheaper than #1). LMArena 1398 (prelim), higher than 2.6 Flare. Risk: not on the deprecation list today but is the previous generation; plan for another migration. Verify real billed tokens.
3. CHEAPER, new vendor: Meta Muse Image, about $0.01. LMArena 1266, AA 1127 (about GPT Image 1.5 level at 1/13 the price). Needs a new integration; official Meta page, data policy and latency unverified.
4. BEST QUALITY PER DOLLAR: Nano Banana 2.1 (`gemini-nano-banana-2.1`), $0.0336 at 1K (batch $0.0168). LMArena 1327 (prelim), AA 1176. Same price as #1 with a higher AA Elo than anything near its price; paid tier is not trained on.
5. PREMIUM: `gpt-image-2.6-sunburst` at high ($0.041) or xhigh ($0.074). Top of both boards. Nano Banana Pro ($0.134) scores below NB 2.1 on LMArena, so skip it.
Floor price, probably too weak: FLUX 3 Image Klein $0.009 (AA 1042), Seedream 5.5 about $0.02-0.03 (AA 1134, official BytePlus price unverified), Qwen-Image 3.0 $0.03.
