# TTS replacement for OpenAI gpt-4o-mini-tts (research read 2026-11-13)

Method: every price below was read today from the provider's own page (URL given) or, for Azure, from Microsoft's official Retail Prices API. Arithmetic: 15 chars/s x 3600 = 54,000 chars per audio hour, so $/hr = ($ per 1M chars) x 0.054. Raw page captures are in `raw/` next to this file.
Our use: one POST per clip, up to 180 s = ~2,700 chars at 15 chars/s (450 words), mp3 out, 180 s timeout, es/fr/de/pt/hi/ur/ja/en.
Third-party measurement: Hindi Voice Bench measured ~650 Hindi chars per spoken minute (~10.8 chars/s), so a real Hindi hour is ~35,000 chars, about 28% cheaper per hour than the 15 chars/s assumption on per-character plans.

## 1. OpenAI (the forced migration)
Source: https://developers.openai.com/api/docs/deprecations (read today); https://developers.openai.com/api/docs/guides/text-to-speech.md; https://developers.openai.com/api/docs/models/gpt-realtime-2.1-mini.md; https://developers.openai.com/api/docs/pricing
- Shutdown 2027-01-06 (notice 2026-10-01): `tts-1`, `tts-1-hd`, `gpt-4o-mini-tts` (+ snapshots 2025-03-20, 2025-12-15). Official replacement: `gpt-realtime-2.1-mini`.
- The TTS guide states: "This is a change of API workflow: gpt-realtime-2.1-mini isn't a supported model for /v1/audio/speech." The model page lists endpoint `v1/realtime` as the only supported route (Speech, Chat Completions, Responses, Batch: Not supported). Transport is WebRTC, WebSocket or SIP. So the official migration is NOT plain HTTP.
- No new `gpt-*-tts` model exists on the pricing page. Audio models listed: gpt-realtime-2.1 / -2.1-mini, gpt-realtime-2 / -1.5 / -mini, gpt-audio-1.5 / gpt-audio / gpt-audio-mini, gpt-live-1 ($0.05/min voice sessions, full-duplex agents, not a TTS), gpt-realtime-translate ($0.034/min).
- Only OpenAI audio-out model reachable over HTTP: `gpt-audio-1.5` via `/v1/chat/completions` ("Supported"; Realtime and speech: not supported). Audio output $64/1M tokens, text in $2.50/1M. `gpt-audio-mini` (HTTP, $20/1M out) is itself deprecated, shutdown 2027-01-20 -> gpt-audio-1.5. Both are chat models, so they may paraphrase a script rather than read it verbatim; I did not test that.
- Prices: gpt-4o-mini-tts text in $0.60/1M, audio out $12.00/1M tokens. tts-1 $15/1M chars, tts-1-hd $30/1M chars. gpt-realtime-2.1-mini audio out $20/1M tokens, text in $0.60/1M. gpt-realtime-2.1 audio out $64/1M.
- OpenAI does not publish audio tokens per minute on the pages I read. Using a third-party estimate of ~1,200 audio output tokens/min (72,000/hr): gpt-4o-mini-tts ~$0.86/hr + ~$0.01 text = ~$0.87/hr; gpt-realtime-2.1-mini ~$1.44 + ~$0.01 = ~$1.45/hr; gpt-audio-1.5 ~$4.61 + ~$0.03 = ~$4.64/hr. (UNVERIFIED token rate.)
- Hindi and Urdu: guide says TTS "generally follows Whisper language support", lists Hindi and Urdu, voices "optimized for English". Realtime language list not checked.
- Data: API data not used for training unless you opt in; abuse-monitoring logs kept up to 30 days; ZDR/Modified Abuse Monitoring by approval. https://developers.openai.com/api/docs/guides/your-data.md
- Artificial Analysis (AA) lists only TTS-1 HD (1108), TTS-1 (1084), GPT-Realtime-2 (1072, $191.56/1M chars as AA computes it). gpt-4o-mini-tts is not on the board.

## 2. ElevenLabs
Sources: https://elevenlabs.io/pricing/api ; https://elevenlabs.io/docs/overview/models.md ; https://elevenlabs.io/docs/overview/capabilities/dubbing.md ; https://elevenlabs.io/docs/eleven-api/resources/zero-retention-mode
- API price per 1K chars (billed in USD, not credits): v4 $0.08; v4 Turbo $0.04; v3 $0.08; v3 Conversational $0.04; v2 Multilingual $0.08; Flash/Turbo $0.04. Plan-included characters work out to the same $80/1M (Creator $22 / 275k).
- $/hr: $80/1M = $4.32/hr (v4, v3, Multilingual v2). $40/1M = $2.16/hr (v4 Turbo, v3 Conversational, Flash).
- Max chars per request: v4 10,000; v3 5,000; Multilingual v2 10,000; Flash v2.5 40,000. mp3: yes (`output_format` mp3_22050_32 ... mp3_44100_192; 192 kbps needs Creator+). Default `enable_logging` true.
- Languages: v4 / v4 Turbo 90+ incl. Hindi (hi) and Urdu (ur); v3 70+ incl. Urdu. `eleven_multilingual_v2` (29 langs) has Hindi but NO Urdu; `eleven_flash_v2_5` (32 langs) has Hindi but NO Urdu. So the cheap Flash tier cannot serve Urdu.
- HTTP vs WebSocket: the models page says "Eleven v4 is available via the Text to Dialogue API" (HTTP) and "Eleven v4 Turbo is available via the Text to Dialogue websocket". It says v3 "can also be used with the Text to Speech API" (POST /v1/text-to-speech/{voice_id}). UNVERIFIED: whether POST /v1/text-to-speech accepts eleven_v4 or eleven_v4_turbo; the repo's key lacks `models_read`, so I could not query GET /v1/models. Safe HTTP choice today is eleven_v3 (5,000 chars is enough for 2,700). Flash v2.5, Multilingual v2 and v3 are documented as plain TTS HTTP models.
- Voice cloning: yes (IVC and PVC; v4 improved; v4 renders other-language text natively rather than carrying the source accent).
- Retention/training: docs say "By default, ElevenLabs retains data, in accordance with the Privacy Policy"; Zero Retention Mode is enterprise-only (`enable_logging=false`), covers /v1/text-to-speech, excludes cloning and dubbing. I did not locate the privacy-policy clause on training; UNVERIFIED.
- ElevenLabs Dubbing API (keeps each speaker's voice; up to 32 speakers; 90+ languages incl. es, fr, de, pt, hi, ur, ja, en in both v1 and v2). Price per SOURCE minute: v1 with watermark $0.33, v1 without $0.50, v2 $2.20. = $19.80, $30.00, $132/hr. Dubbing v2 is labelled Alpha; transcript editing via API is Enterprise only; no ZRM for dubbing. For a 180 s clip: $0.99-$1.50 (v1) or $6.60 (v2) vs $0.216 for v4 TTS. Different product (needs source audio) and 5x-30x dearer.
- Leaderboards: AA (English) Eleven v4 1340, v4 Turbo 1339, v3 Conversational 1214, v3 1189, Multilingual v2 1093, Flash v2.5 1074. HF TTS Arena V2: Eleven v3 1521 (preliminary), Multilingual v2 1507, Flash v2.5 1503; no v4 listed.

## 3. Google
Sources: https://aistudio.google.com/docs/pricing (redirect of ai.google.dev) ; https://cloud.google.com/text-to-speech/pricing ; https://aistudio.google.com/docs/speech-generation ; https://cloud.google.com/text-to-speech/docs/chirp3-hd ; https://cloud.google.com/text-to-speech/quotas ; https://cloud.google.com/text-to-speech/docs/data-logging
- Gemini 3.8 Flash TTS (`gemini-3.8-flash-tts`, "Preview" on Cloud page): audio out $9.00/1M tokens through 2026-12-31, $18.00 from 2027-01-01; text in $0.50 -> $1.00. Batch half.
- Gemini 3.8 Flash-Lite TTS (`gemini-3.8-flash-lite-tts`): audio out $6.00/1M through 2026-12-31, $12.00 from 2027-01-01; text in $0.50 -> $1.00. Batch half.
- Older: 3.1 Flash TTS preview $20/1M; 2.5 Flash preview TTS $10/1M; 2.5 Pro preview TTS $20/1M.
- Google says audio = 25 tokens/s, so 90,000 tokens/hr: 3.8 Flash $0.81/hr now, $1.62/hr from 2027-01-01; Flash-Lite $0.54 now, $1.08 from 2027-01-01. Hindi Voice Bench (third party, single maintainer, 2026-09-28) measured 37-41 output tokens/s on Google's own meter: at 41 tok/s that is $1.33 and $0.89/hr now and $2.66 and $1.77/hr from 2027. Plan on the higher number until you measure.
- Gemini API: HTTP, input limit 8,192 tokens (fine for 450 words), output WAV (unary, 24 kHz mono) or raw PCM; NO mp3 (transcode with ffmpeg). Hindi: yes (both models). Urdu: NOT in the supported-language table (it lists Kashmiri, Sindhi, Punjabi, Persian but no Urdu). 130+ languages (Flash), 100+ (Flash-Lite). Voice replication, design, remix: yes (POST /v1beta/voices).
- Data (Gemini API paid services): prompts/responses not used to improve products; abuse-monitoring retention 55 days by default (configurable 7/14/28/55). Unpaid tier may be used for training. https://ai.google.dev/gemini-api/terms ; https://ai.google.dev/gemini-api/docs/logs-policy
- Cloud TTS Chirp 3: HD: $30/1M chars (1M chars free/month) = $1.62/hr; Instant custom voice $60/1M. Languages include hi-IN and ur-IN (Urdu India; no ur-PK). Max 5,000 BYTES per request: Devanagari is 3 bytes/char (~1,600 chars) and Arabic-script Urdu 2 bytes/char (~2,500 chars), so 2,700-char Hindi clips need 2 requests. MP3 supported on the non-streaming method. Streaming = bidirectional gRPC. Data: "Google does not log any customer Cloud TTS text or audio data."
- AA (English): Gemini 3.8 Flash TTS 1284, Flash-Lite 1260, 3.1 Flash 1213, Chirp 3: HD 1061, Studio 1073, Neural2 890. Hindi Voice Bench round 1 (2026-09-26, 170 clips, AI listener = Gemini 3.1 Pro, so possibly biased): Gemini 3.8 Flash-Lite TTS led Hindi audio drama.

## 4. Azure Speech
Sources: Microsoft Retail Prices API (https://prices.azure.com/api/retail/prices, serviceName 'Foundry Tools', read today); https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support ; .../rest-text-to-speech ; .../responsible-ai/speech-service/text-to-speech/data-privacy-security
- Neural TTS (S1) $15.00/1M chars = $0.81/hr. Neural HD $22.00/1M = $1.19/hr. Personal voice $24/1M. (The public pricing page renders "$-" without JS, so I used the API; MAI-Voice-2 price NOT found.)
- Languages: hi-IN has many neural voices plus HD and MAI-Voice-2 / MAI-Voice-2-Flash voices; ur-PK (Uzma, Asad Neural) and ur-IN (Gul, Salman Neural) exist as standard neural voices. I did not find an Urdu HD voice.
- HTTP REST (SSML body, `cognitiveservices/v1`), audio capped at 10 min per request (fine for 180 s), many mp3 formats. Data: "Neither input text nor output audio content is stored in Microsoft logs" for prebuilt neural voices; custom data only used for that customer's voice.
- Voice cloning: Personal Voice / Custom Neural Voice, limited access.
- AA (English): Azure HD 2.5 1145, Azure Neural 1032, MAI-Voice-1 1025. Quality of the plain neural tier is well below the LLM-era models.

## 8. Shortlist to audition
1. Default: Inworld `inworld-tts-2`. $1.35/hr, AA 1268, Hindi Tier 1, Urdu Tier 2, and an OpenAI-compatible `/v1/audio/speech` endpoint (mp3, 4,000 chars) so the call site barely changes; a 2,700-char clip fits in one request. Contract says no training on non-public content. Risk: Urdu is Tier 2, retention not stated.
2. Cheaper: Inworld `inworld-tts-2-flash` ($0.81/hr, same integration, AA 1215, same language list) and, as the price/Elo outlier, Speechify Simba 3.5 ($0.54-$0.81/hr, AA 1294, hi + ur voices; confirm the $10 launch price ends 2026-11-21 and chunk to 2,000 chars). Azure Neural ($0.81/hr) is the only one with native ur-PK and a clean no-logging policy but its plain neural quality is far lower.
3. Premium: ElevenLabs v4 ($4.32/hr, AA 1340, Hindi + Urdu, cloning). Verify first that your key can call v4 on the TTS endpoint; fall back to `eleven_v3` ($4.32/hr, HTTP documented, 5,000 chars). v4 Turbo is half the price at AA 1339 but documented only for the Text to Dialogue WebSocket.
Also audition: Cartesia Sonic 3.6 (AA 1294, Hindi + Urdu + Hinglish, but trains on content by default). Gemini 3.8 Flash-Lite only if Urdu is split out (no Urdu listed, no mp3, price doubles on 2027-01-01).
Not recommended: OpenAI gpt-realtime-2.1-mini (WebSocket workflow, pricier than today), MiniMax (dear, no Urdu), Sarvam (no Urdu), Hume (ended), ElevenLabs Dubbing (5x-30x cost, different product).
