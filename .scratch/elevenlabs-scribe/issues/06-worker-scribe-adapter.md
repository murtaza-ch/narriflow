## Comments

- `transcribe.ts` rewritten end to end; every AssemblyAI function, constant and env var is gone. Submit: requested language (`toProviderLanguageCode`) else `probeSourceLanguage` on a 4 h presigned URL, then `beginProviderSubmission(deadline = now + 10 min)` **after** any audio extraction and **before** the single, never-retried POST, then `recordProviderAcceptance(nextPollAt = now + 30 s)`. Input is `source_url` on attempt 1 with `sourceSizeBytes <= 2 GiB` and a working presign, else mono 16 kHz mp3 streamed from disk (`fs.openAsBlob`, disk-backed `Blob`, never a Buffer). A failure after begin goes through `failProviderAttempt` (no-op if stale), before begin through `failAttempt`.
- Results loop: null id -> `expireUnconfirmedProviderSubmission`; else GET. 200 -> `finalizeScribeTranscript({key, payload, providerIds:{transcriptionId}})` (the claim does not carry the request id and the GET body has none, so only the transcription id is passed); `404 transcript_not_found`, 429/5xx/network -> next tick until the result deadline (`ELEVENLABS_RESULT_TIMEOUT_MS`, default 2 h from `waitingSince`) -> retryable `elevenlabs_transcription_timeout`; 401/403/other 404/other 4xx -> permanent. A ready transcript is finalized even past the deadline. `ELEVENLABS_RESULT_POLL_INTERVAL_MS` (30 s) is the per-run claim gap.
- Error codes: `elevenlabs_{api_key_missing,webhook_not_configured,auth_failed,quota_exhausted,invalid_media,invalid_language}` permanent; `elevenlabs_{transcription_submit_failed,transcript_fetch_failed,transcription_timeout}` retryable. Classified on `detail.code/status/type` + HTTP status; messages never contain provider prose. User copy added in `error-messages.ts` for all of them (+ `elevenlabs_result_invalid`, `elevenlabs_submission_unconfirmed` from earlier tickets).
- `WorkflowRunLifecycle.waitForProvider` deleted; its two db tests (shutdown release keeps an accepted transcript waiting; waiting STT is not reaped) now use `beginProviderSubmission` + `recordProviderAcceptance`. `ClaimedWorkflowAttempt.project` gained `sourceSizeBytes` (needed for the 2 GiB policy).
